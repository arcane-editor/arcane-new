ArcaneIDE is built on Eclipse Theia and supports the same theme ecosystem.

## Switching Themes

Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) and type **"Color Theme"** to browse installed themes.

## Default Theme

Arcane ships with a dark theme enabled by default — deep navy background with orange accents, matching the branding.

## Installing More Themes

Theia supports VS Code-compatible themes. You can install additional themes through the Extensions panel or by manually adding theme packages to the application.
