title: Navigation

---

ArcaneIDE provides fast navigation tools to keep you in flow.

## File Explorer

The left sidebar shows your project tree. Click any file to open it in a new tab.

## Quick Open

Press `Ctrl+P` / `Cmd+P` to fuzzy-search for files by name.

## Go to Symbol

Press `Ctrl+Shift+O` / `Cmd+Shift+O` to jump to a class, method, or field in the current file.

## Go to Definition

`F12` or `Ctrl+Click` on any symbol to jump to its definition.

## Breadcrumbs

The breadcrumb bar at the top of the editor shows your current location in the file hierarchy and symbol tree.
